# Abstract

The abstract was written using [Typst](https://typst.app/).

## How to build

1. Install `typst` through your method of choice.
1. Build with `typst`:
  ```bash
  typst compile abstract.typ
  ```
1. Open the `abstract.pdf` file that got created.

### How to live edit

You can use `typst watch abstract.typ` to live preview the document as you edit it.
